# SafeStep 발표 대본 (5분)

> 말하는 속도 기준 약 5분 (1분에 300자 안팎). 괄호 시간은 누적 목표.
> **굵은 글씨**는 강조해서 읽을 부분, `/`는 잠깐 쉬는 곳.

---

### 1. 표지 (~0:15)
안녕하세요, [이름]입니다. / 제 프로젝트는 **SafeStep**, 보행자 시점 사진을 보고 위험 요소와 피하는 방법을 **한국어 문장으로 안내하는 비전-언어 모델**입니다.

### 2. 문제 제기 (~0:40)
시각장애인 보행 보조에 객체 검출을 쓰면 "자동차 0.91" 처럼 무엇이 어디 있는지만 알려 줍니다. / 하지만 실제로 필요한 건 **"그래서 어떻게 해야 하는가"** 입니다. / 그래서 저는 이 문제를 검출이 아닌 **생성 문제**로 정의했습니다. 모델은 위험도, 위험 요소, 그리고 바로 읽어 줄 수 있는 안내 문장을 JSON으로 출력합니다.

### 3. 접근 방법 (~1:00)
방법은 **지식 증류**입니다. / 큰 7B 모델과 규칙으로 라벨을 만들고, 검수를 거친 뒤, 작은 **3B 모델을 4bit와 LoRA로 학습**합니다. / 한국 보도 환경, 구조화된 출력, 그리고 노트북에서도 도는 가벼운 모델이 차별점입니다.

### 4. 데이터셋 ① (~1:30)
데이터는 **AI Hub 인도보행 영상**에서 1,452장을 뽑았습니다. / 처음엔 7B 모델에게 라벨을 통째로 맡겼는데, 위험도를 **20장 모두 '보통'**으로 답하고, 오른쪽에 차가 있는데 오른쪽으로 비키라는 위험한 안내까지 나왔습니다. / 그래서 **판단은 정답 박스와 깊이 정보로 규칙이 하고, 모델은 문장만 다듬도록** 바꿨습니다.

### 5. 데이터셋 ② (~2:00)
테스트 100장은 직접 검수해서 정답으로 고정했습니다. / 수정 사유 1위는 **횡단보도 누락**이었습니다. AI Hub 박스에는 노면 정보가 없기 때문입니다. / 그래서 7B 모델에게 "앞에 횡단보도가 있나" 예/아니오만 묻는 VQA를 추가했고, 발 앞 영역만 잘라 묻는 방식으로 **정밀도를 0.29에서 0.75까지** 올렸습니다. / 분할은 시퀀스 단위로 해서 비슷한 장면이 train과 test에 섞이지 않게 했습니다.

### 6. 데이터 분포 (~2:10)
학습 데이터는 세 위험 등급이 고르게 섞여 있고, / 바리케이드처럼 드문 클래스도 있다는 점은 뒤에서 다시 말씀드리겠습니다.

### 7. 모델 (~2:35)
모델은 **Qwen2.5-VL**입니다. 이미지를 패치 토큰으로 바꿔 언어 모델에 넣는 구조입니다. / 베이스는 4bit로 고정하고, **저랭크 행렬만 학습하는 LoRA**를 붙여서 전체의 **0.8%**만 학습했습니다. / 손실은 정답 JSON 부분에만 걸었습니다.

### 8. 학습 (~3:00)
AI Hub는 해외 다운로드가 막혀 있고 국외 반출도 제한돼서, Colab 대신 **맥북에서 Apple의 MLX로** 전부 학습했습니다. / 2 에폭에 약 3시간 반, 메모리 6GB 이내였고, / 검증 손실이 끝까지 내려가서 과적합은 없었습니다.

### 9. 결과 (~3:30)
결과입니다. / 학습한 3B 모델이 **라벨을 만든 7B 모델보다도 모든 지표에서 높았습니다.** / 위험요소 F1은 **0.23에서 0.73**으로 올랐고, 7B보다 **1.5배 빠르고** 메모리도 적게 씁니다. / 판단을 규칙과 검수가 맡았기 때문에 학생이 선생을 넘을 수 있었습니다.

### 10. 분석 (~3:50)
학습 전 모델은 모든 장면을 '높음' 하나로만 답했습니다. / 그래서 정확도 대신 **macro-F1**로 보면 0.20에서 **0.55**로 올랐고, / 정면 횡단보도 12장은 **LoRA 모델만 전부** 찾았습니다.

### 11. 정성 분석 (~4:05)
틀린 경우는 대부분 위험도를 **한 단계 높게** 말하는 경우였는데, 보행 안내에서는 안전한 쪽 오류입니다. / 화면 가장자리 물체와 드문 클래스는 아직 약합니다.

### 12. 문제와 해결 (~4:25)
가장 큰 문제 두 가지만 말씀드리면, / AI Hub 해외 차단 때문에 **전 과정을 맥으로 옮긴 것**, / 그리고 학습 중 **NaN**이 났는데, 4bit 모델이 실제로 float16이라 생긴 문제여서 **bfloat16으로 변환**해 해결했습니다.

### 13. 데모 (~4:50) — 데모 영상 재생
데모입니다. / 사진을 넣으면 학습한 모델은 위험 요소를 짚어 안내하고, 학습 전 모델과 비교할 수 있습니다. / 동영상은 몇 초마다 분석해서 **안내가 타임라인으로 쌓입니다.** 영상은 대기 시간을 빨리 감았습니다. / 앞으로는 속도 개선과 야간 장면 보강이 과제입니다.

### 14. 마무리 (~5:00)
코드와 라벨 데이터셋 링크는 슬라이드에 있습니다. / 들어 주셔서 감사합니다.

## 녹화 팁
- 5분을 넘기면 6번(데이터 분포)과 11번(정성 분석)을 한 문장으로 줄이세요.
- 13번에서 데모 영상(36초)이 재생되는 동안 위 대본을 말하면 시간이 맞습니다.
- 숫자는 천천히: "영 점 이 삼에서 영 점 칠 삼".
